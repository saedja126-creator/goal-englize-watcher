Hard rules the code enforces

Position size

About 7% of the account per trade, capped near 1% of pool liquidity.

Risk per trade

0.5–1% of the account at the stop.

Daily loss limit

About 5%. The desk halts and waits for you.

Project stop

Live trading halts if the live slice falls 30%: £60 on £200, £150 on £500.

One position at a time

No new scan while a position is open.

No keys in the bot

Shadow mode has no wallet. Later: a separate burner wallet.

All values are proposals, tuned from shadow data. No model can override them.

These limits live in code, not in a prompt, so nothing can talk the system out of them. The blue cards limit how much any single trade can cost. The orange cards limit how much the whole project can lose.
