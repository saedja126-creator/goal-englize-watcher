What will and will not ping you. Today the watchdog alerts you if the scanner dies and cannot be restarted, and tells you when it is back. The weekly report always arrives as a file on Sunday evening. The Telegram notice that the report is ready is new and needs the code update and a restart of the scanner. Calendar reminders for key dates and an alert for the loss limits are not set up yet. There are no daily updates, as you asked.
