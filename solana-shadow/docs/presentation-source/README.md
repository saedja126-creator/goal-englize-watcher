# Presentation source (23 slides)

The published artifact (https://claude.ai/artifact/3U9QE1hLhyzLipnj3b4t44, type "Slides") is made of `project/deck.json` (slide order) and
`project/slides/<id>.html` (one file per slide). This folder is a copy of those files as of 28 Oct 2026.

- **Offline copy:** `python3 -I build_deck_html.py . ../Shadow_Desk_presentation.html` (run inside this folder). Open the HTML, arrow keys to move, Ctrl+P to save as PDF.
- **Update the live artifact (same claude.ai account):** read the artifact by URL with the Artifact tool, edit the slide files, publish to the same URL with the downloaded folder as `root`.
- **Recreate it elsewhere:** publish a new Artifact from the Slides type (`type_url` https://claude.ai/artifact/8jTsAFQMFDb2oA8MsPJ2eL), then send `project/deck.json` and `project/slides/*.html`.
- Slide text is also in `../MASTER_PLAN.md`, Appendix A.
